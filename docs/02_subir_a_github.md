# 02. Subir el proyecto a GitHub

## Preparación
Antes de subirlo, reviso que el archivo `.env` no vaya al repositorio.

## Comandos
```bash
git init -b main
git add .
git commit -m "Actualizar Impulso REP"
git remote add origin https://github.com/Rolando-rivera/impulsorep.git
git push -u origin main
```

## Qué revisar en GitHub
- Que existan las carpetas `frontend`, `backend`, `sql` y `docs`.
- Que el README principal se vea ordenado.
- Que no se suban credenciales reales.
