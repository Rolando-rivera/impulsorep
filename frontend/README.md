# Frontend Impulso REP

Interfaz Vue 3 + Vite + Bootstrap 5.

En desarrollo local:

```cmd
npm install
npm run dev
```

El archivo `frontend/.env` puede usar:

```env
VITE_API_URL=http://localhost:3000
```

En producción con Koyeb no se debe colocar `DATABASE_URL` en el frontend. La conexión a Neon se maneja solo desde el backend.
